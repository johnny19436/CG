2. 主視覺化 — GPU（約 2.5～3 分鐘）★重點★
  含：染料互動、場切換、黏滯擴散說明
================================================================================

【指令】
  ./build/fluid_sim visualize --backend gpu --width 512 --height 512 --iters 40 \
    --viscosity 0.00001 --diffusion-iters 20 --dt 0.1 --steps-per-frame 1 --field dye --vsync 1

【口播 — 啟動】
  現在我執行 visualize，backend 設為 gpu。
  512 乘 512 格點，每步 40 次 Jacobi 壓力迭代，dt 0.1，每幀推進一步，field 是 dye。
  我們有開啟黏滯：--viscosity 與 --diffusion-iters 20，
  在平流之後、加外力之前，用 Jacobi 做速度的隱式擴散，符合第 38 章完整流程。

  模擬在 CUDA 上跑，顯示用 CUDA–OpenGL PBO 互操作，不必每幀把整張格點抄回 CPU。

【口播 — 畫面】
  紫色、深藍是低濃度，黃橘是高濃度。程式有固定中心外力，不碰滑鼠也會持續流動。
  有黏滯時，渦旋會比較快被抹平，整體運動較平滑，細小結構較快消失。

【動作 + 口播 — 滑鼠】
  （左鍵拖曳 5～8 秒，畫 8 字）

  按住左鍵拖曳會在游標處注入外力與染料：外力改變速度，染料顯示流向。
  會出現渦旋、拉伸與混合；擴散讓速度場稍被平滑，所以尾跡不會一直銳利地抖動。

  （橫向快掃拖曳一次）快速掃過會拉出不同的剪切與尾跡。

【動作 + 口播 — 鍵盤】
  （Space）空白鍵暫停／繼續，方便定格。
  （1）速度量值，亮處流速大。
  （2）壓力場，和不可壓縮求解有關。
  （3）散度，投影後應維持很小。
  （4）回染料，再拖曳 3～4 秒，觀察渦旋隨時間被黏滯抹平。

  （Esc）主視覺化結束。接下來比 CPU 與 GPU 互動流暢度。

3. CPU 與 GPU 對比（約 1.5～2 分鐘）
================================================================================

【口播 — 過場】
  接下來加重負載做對比：1024 平方、每幀 16 個物理步（steps-per-frame 16）、
  壓力 Jacobi 80 次（--iters 80）。CPU 關 vsync 看終端機真實 FPS，再換 GPU 同參數。

【指令 — CPU】
  ./build/fluid_sim visualize --backend cpu --width 1024 --height 1024 --iters 80 \
    --dt 0.1 --steps-per-frame 16 --field dye --vsync 0

【口播 + 動作】
  標題是 CPU backend：每一幀要連算 16 步，每步又含 80 次壓力迭代，
  再加上 host 上色與上傳 OpenGL，負擔非常大。

  （左鍵拖曳 6～8 秒）攪動反應遲鈍、畫面明顯卡頓。
  （指終端機）CPU FPS 通常只有個位數，甚至更低。

  （Esc）

【口播】完全相同參數，只把 backend 改成 gpu。

【指令 — GPU】
  ./build/fluid_sim visualize --backend gpu --width 1024 --height 1024 --iters 80 \
    --dt 0.1 --steps-per-frame 16 --field dye --vsync 0

【口播 + 動作】
  同樣每幀 16 步、80 次 Jacobi，模擬留在 GPU 並行更新。

  （同樣拖曳）流體仍跟得上滑鼠，畫面明顯比 CPU 順；同一套物理，差在算力與記憶體頻寬。

  （Esc）
